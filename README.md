# Recruit Server

A Node.js backend for the Recruit application, developed as a personal project while expanding my full-stack web development skills.

This project provides RESTful APIs, user authentication, MongoDB data management, and real-time communication using Socket.IO. It serves as the backend service for the Recruit Client application.

## 🚀 Frontend Project

Frontend repository:
https://github.com/renehu/recruit-client

Live Demo:
https://renehu.net/recruit-client/#/login

## Features

- RESTful API development
- User authentication and authorization
- MongoDB database integration
- Real-time messaging with Socket.IO
- CRUD operations
- JSON Web Token (JWT) authentication
- Express middleware
- Error handling and request validation

## Tech Stack

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- Socket.IO
- JSON Web Token (JWT)

## API Overview

The backend provides APIs for:

- User authentication
- Employee and employer management
- Recruitment management
- Real-time chat
- Database operations

## Purpose

This project was developed as a personal project to strengthen my backend development skills using Node.js, Express, MongoDB, and Socket.IO.

It demonstrates my understanding of RESTful API design, database modelling, authentication, real-time communication, and frontend-backend integration.
